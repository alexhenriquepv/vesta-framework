# Glycemia use case

This use case provides an example of business logic applied in the framework flow.

---

## `glycemia_level.py`

This file defines a `ProcessingTask` named `GlycemiaLevelTask`, which is responsible for processing an event related to blood glucose levels.

* **Functionality**: The `GlycemiaLevelTask` analyzes the data from a received event and determines if the blood glucose level is "HIGH", "LOW", or "NORMAL".
* **Business Logic**:
    * If the glucose value is above 180, the status is set to "HIGH".
    * If the value is below 70, the status is set to "LOW".
    * Otherwise, the status is "NORMAL".
* **Action Registry**: It registers two `ActionTasks` available for LLM use: `alert_emergency_contact` and `send_push_notification`. 
* This enables the `Planner` to invoke these functions based on the LLM's response.
* **Return Value**: The task returns a structured dictionary containing the glucose value, the calculated status, 
* and user profile information, which is then used by the `Planner` to format the prompt for the LLM.

## Defining Glycemia Level Processing Task

`tasks/processing/glycemia_level.py`

```python
from model.event import Event
from resources.mocked_helpers import get_user_profile
from tasks.actions.alert_emergency_contact import alert_emergency_contact
from tasks.actions.send_push_notification import send_push_notification
from tasks.processing.processing_task import ProcessingTask

class GlycemiaLevelTask(ProcessingTask):

    def __init__(self, event: Event):
        super().__init__(event, prompt_name="glycemia_level")

    @property
    def action_registry(self):
        return {
            "alert_emergency_contact": alert_emergency_contact,
            "send_push_notification": send_push_notification,
        }

    def run(self):
        value = self.event.data
        if value > 180:
            status = "HIGH"
        elif value < 70:
            status = "LOW"
        else:
            status = "NORMAL"

        return {
            "value": value,
            "status": status,
            "user_profile": get_user_profile(),
        }
```

## Event Data structure

The Event Data Structure for this action it's a json structure with:

1. `task_name` (string): The Processing Task that will be executed;
2. `data` (any): The data payload to be used by the task as value.
3. `metadata` (any): Additional information to contextualize LLM.

```json
{
  "task_name": "GlycemiaLevelTask",
  "data": 182,
  "metadata": {
    "diabetes_family_history": true
  }
}
```
